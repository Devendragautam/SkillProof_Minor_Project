Functional Module Hierarchy and State Flow of the Candidate Verification Flow
1. Resume IntakeFile upload or paste; sample resume for demo runs
2. AI Skill ExtractionClaimed skills mapped onto the 12-skill catalog with heuristic fallback
3. Profile ConfirmationCandidate confirms skills + claimed level per skill
4. Plan GenerationbuildPlan deals a 10-question hybrid mix from those claims
5. Proctored Assessment Runner — full exam screen Question palette (skip / return) · Monaco editor with visible + hidden tests · JavaScript, Python, C++, Java · real SQL execution · per-question server deadline countdown · disclosed session evidence panel · two-strike tab-switch auto-submit · per-question hint (scored cost)
6. Explain-the-CodeGenerated questions on the candidate's own submission; consistency scored
7. Evidence ReportOverall score, confidence band, AI-assist risk, skill-wise percentages
8. Verified ProfileCertificate SP-code, QR sheet, downloadable PDF, public verify link
Every stage is server-authoritative: browser clocks are never consulted, and any mutation after the assessment deadline is rejected.
