Entity-Relationship Model of the SkillProof Verification Database
CANDIDATE
PK id (cuid)
name, email (indexed)
tags, notes, archived, invited
pipelineStatus, pipelineNote
pipelineMetaJson
1 : N Resume · 1 : N Assessment · 1 : N Certificate · 1 : N PipelineEvent
RESUME
PK id
FK candidateId (CASCADE)
fileName, rawText
skillsJson (extracted)
N : 1 Candidate
ASSESSMENT
PK id
FK candidateId (CASCADE)
status, planJson
startedAt, expiresAt
completedAt
N : 1 Candidate · 1 : N AssessmentQuestion · 1 : 1 Report · 1 : 1 Certificate
ASSESSMENT_QUESTION
PK id
FK assessmentId, FK questionId
status, score, attempts, hintCount
activeFlag (@@unique w/ assessment)
dealtAt, deadlineAt, timeLimitSec
N : 1 Assessment · N : 1 Question · 1 : 1 Submission
QUESTION
PK id · UK externalId
skill (12), topic, difficulty
category: coding / debugging / mcq
testsJson, optionsJson, hint
schemaSql, seedSql, solutionSql
1 : N AssessmentQuestion (reusable pool)
SUBMISSION
PK id · UK assessmentQuestionId
code, language, eventsJson
versionsJson, metricsJson
testResultsJson, runtimeMs
aiRiskScore, analysisJson
1 : N ExplanationAnswer
EXPLANATION_ANSWER
PK id
FK submissionId
questionText, answerText
consistencyScore, aiFeedback
N : 1 Submission
REPORT
PK id · UK assessmentId
overallScore, confidence
aiRiskScore + signals
skillScoresJson, breakdownJson
shareToken (UK, 192-bit)
1 : 1 Assessment
CERTIFICATE
PK id · UK code (SP-XXXX-XXXX)
UK assessmentId (1 : 1)
FK candidateId
scoresJson, overallScore
issuedBy, cohortStandingJson
1 : 1 Assessment · N : 1 Candidate
Supporting entities: USER (scrypt passwordHash, role recruiter | candidate) · TIMER_POLICY (per-section limits, skill overrides, proctor severity thresholds) · PIPELINE_EVENT (decision audit trail with metadata snapshots) · PROCTOR_EVENT_RECORD (durable proctor transcript, indexed by assessment + ts) · FIT_PRESET (saved role-fit weight profiles).
Notation: PK = Primary Key · UK = Unique Key · FK = Foreign Key · CASCADE = cascading delete. All deletions cascade from CANDIDATE and ASSESSMENT.
