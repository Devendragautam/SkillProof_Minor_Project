Four-Tier Cloud-Backed System Architecture of SkillProof
Tier 1 — Presentation Layer (React 19 Single-Page Client)
Candidate FlowResume upload, claimed-skill confirmation, proctored assessment runner, verified profile
Recruiter WorkspaceOverview, candidates register, question bank, live monitoring, reports, certificates
Public VerifyCertificate verification by code, share-token report views, landing comparisons
Tailwind CSS 4 · shadcn/ui · Zustand state · TanStack Query · self-hosted Monaco Editor
Tier 2 — API Gateway and Authorization Layer (Next.js App Router)
43 Route Handlers/api/auth, /api/assessment, /api/candidates, /api/questions, /api/certificates, /api/report …
Session MiddlewareHMAC-signed httpOnly cookie, role resolution, timing-safe credential checks
Centralized Guardsguards.ts — authentication first, then resource ownership, then state (401 / 403)
Zod-style input validation · per-route rate limiting · audit logging
Tier 3 — Domain Services and Business Logic (TypeScript)
Adaptive EnginebuildPlan hybrid selection, difficulty stepping, question dealing
Execution SandboxesJavaScript isolate, Python / C++ / Java runners, real SQL executor
AI ServiceSkill extraction, MCQ import, explain generation and consistency scoring
Document EngineCertificate and evidence-report PDF builders, QR verification seals
Server-authoritative timers · evidence metrics · AI-assist risk signals · cohort analytics
Tier 4 — Persistence Layer (Prisma ORM)
SQLite Relational Store — 14 Normalized EntitiesUsers, Candidates, Resumes, Questions, Assessments, Submissions, Reports, Certificates, TimerPolicy, PipelineEvent, ProctorEventRecord …
Cascading foreign keys · composite indexes · single-active-question invariant (@@unique)
Real-Time Proctoring
Microservice socket.io · port 3003
  • Candidate event stream (edits, pastes, focus changes, test runs)
  • Recruiter room broadcast — live session cards
  • Bounded retry queue flushing durable transcripts to the ingest API
  • /healthz liveness probe
Notation: HTTPS JSON request–response between tiers 1–3; socket.io duplex stream between the client and the proctoring microservice.
